☁️ Guide: Free Google Drive Auto-Backup

Want every click of "Save to Google Drive" to automatically upload the backup file to your Google Drive folder for free? Follow these 3 easy steps:

  1. Open Google Apps Script (script.google.com) using your Gmail account, then click "New Project".
  2. Delete the existing code in the editor and paste this short snippet: 
    function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var folder = DriveApp.getRootFolder();
  var file = folder.createFile(data.filename, data.content, MimeType.PLAIN_TEXT);
  return ContentService.createTextOutput(JSON.stringify({
    success: true,
    file_url: file.getUrl()
  })).setMimeType(ContentService.MimeType.JSON);
}
  3. Click Deploy > New deployment. Select Web app, set Who has access to Anyone, then click Deploy.
  4. Copy the generated Web App URL, paste it into the Google Drive Webhook / Apps Script URL field here in Admin Settings, and save!
