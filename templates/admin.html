☁️ Giya: Libre nga Google Drive Auto-Backup

Gusto ka nga sa matag click nimo ug "I-Save sa Google Drive", awtomatikong mosulod ang file sa imong Google Drive folder nga walay bayad? Sunda kining 3 ka sayon nga lakang:

  1. Ablihi ang Google Apps Script (script.google.com) gamit ang imong Gmail account, unya i-click ang "New Project".
  2. I-delete ang sulod sa editor ug i-paste kining mubo nga code: 
    function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var folder = DriveApp.getRootFolder();
  var file = folder.createFile(data.filename, data.content, MimeType.PLAIN_TEXT);
  return ContentService.createTextOutput(JSON.stringify({
    success: true,
    file_url: file.getUrl()
  })).setMimeType(ContentService.MimeType.JSON);
}
  3. I-click ang Deploy > New deployment. Pilia ang Web app, ibutang sa Who has access: Anyone, unya i-click ang Deploy.
  4. Kopyaha ang gihatag nga Web App URL ug i-paste kini sa kahon sa Google Drive Webhook / Apps Script URL dinhi sa Admin Settings, dayon i-save!
